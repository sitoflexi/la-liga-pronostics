Configuración inicial

Solo se hace una vez (y cuando caduque el token). El token se guarda cifrado con la contraseña; sin ella no sirve de nada.

  1. Abre GitHub → Fine-grained token nuevo con la cuenta dueña del repo.
  2. Nombre: liga-admin. Caducidad: la máxima que permita (1 año).
  3. Repository access → Only select repositories → la-liga-pronostics.
  4. Permissions → Repository → Contents: Read and write. Nada más.
  5. Genera el token, pégalo aquí y elige una contraseña larga (mín. 12 caracteres).

Partidos y resultados

Formato del resultado: 2-1. Déjalo vacío si el partido aún no se ha jugado.

Pronósticos

Un pronóstico por casilla (2-1). El círculo marca el comodín del jugador (puntos ×2); uno por jugador y jornada.

Jugadores y bote

Bote acumulado de cada jugador en euros.

Sesión

Cambiar la contraseña cifra el mismo token con la nueva contraseña.
